# Code of Conduct

## Our Standards

We are committed to a respectful, welcoming, and technically constructive
community. Examples of positive behavior include:

- Being considerate and clear in technical discussion.
- Respecting different experience levels, backgrounds, and viewpoints.
- Giving actionable feedback and accepting correction gracefully.
- Focusing disagreement on ideas, evidence, and project goals.
- Protecting other people's privacy and credentials.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate disruption, publishing private information, or exposing
another person's credentials without permission.

## Scope

This code applies in project repositories, issues, pull requests, discussions,
release channels, and other spaces where someone is representing the project.

## Enforcement

Maintainers may edit or remove contributions that violate these standards and
may temporarily or permanently restrict participation. Enforcement decisions
should be proportionate, documented privately, and protect the reporter's
privacy where possible.

Report conduct concerns privately using the reporting path in `SECURITY.md`.
Do not include sensitive personal information in a public issue.
